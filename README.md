### Задание 1. Кеширование 

Приведите примеры проблем, которые может решить кеширование. 

*Приведите ответ в свободной форме.*

---

Проблемы, которые решает кеширование:
Медленный доступ к данным → Ускоряет за счёт хранения в быстрой памяти.

Высокая нагрузка на БД/серверы → Снижает число запросов к источнику.

Большие задержки у удалённых пользователей → CDN и edge-кеширование.

Повторные тяжёлые вычисления → Сохраняет результаты расчётов.

Пиковые нагрузки (например, Black Friday) → Поглощает часть трафика.

Временная недоступность сервиса → Отдаёт закешированные данные.

Дорогие API/хранилища → Сокращает затраты на внешние запросы.

Примеры: Веб-страницы, Redis, CDN, кеш игровых ресурсов.
