### Задание 1. Резервное копирование

### Кейс
Финансовая компания решила увеличить надёжность работы баз данных и их резервного копирования. 

Необходимо описать, какие варианты резервного копирования подходят в случаях: 

1.1. Необходимо восстанавливать данные в полном объёме за предыдущий день.

1.2. Необходимо восстанавливать данные за час до предполагаемой поломки.

*Приведите ответ в свободной форме.*

### 1.1. Восстановление данных в полном объёме за предыдущий день
**Подходящий вариант:** Полное резервное копирование (Full Backup)

- **Частота:** Ежедневно  
- **Плюсы:**  
  - Простота восстановления (требуется только последний бэкап)  
- **Минусы:**  
  - Большой объём хранилища  
  - Долгое время создания бэкапа 

**Пример команды для PostgreSQL:**  
```bash
pg_dump -U username -d dbname -f backup_full.sql
```

**Пример для MySQL:**
```sql
mysqldump -u root -p --all-databases > full_backup.sql
```

### 1.2. Восстановление данных за час до поломки

**Подходящий вариант:** Комбинация Full + Incremental/Differential Backup

**Incremental Backup:**
- Сохраняет только изменения с последнего бэкапа
- Плюсы: Быстрый, экономит место
- Минусы: Для восстановления нужна цепочка всех инкрементных бэкапов

**Differential Backup:**
- Сохраняет изменения с момента последнего полного бэкапа
- Плюсы: Быстрое восстановление (нужен только полный + последний дифференциальный)
- Минусы: Размер растёт со временем

**Оптимальное решение:**
- Полный бэкап раз в сутки
- Инкрементные/дифференциальные каждые несколько часов

**Альтернатива:**
- Транзакционные логи (Transaction Log Backup) для PITR

### Задание 2. PostgreSQL

2.1. С помощью официальной документации приведите пример команды резервирования данных и восстановления БД (pgdump/pgrestore).

*Приведите ответ в свободной форме.*

### 2.1. Резервирование и восстановление PostgreSQL

**Резервирование (pg_dump):**
```bash
pg_dump -U username -d dbname -F c -f backup.dump
```

**Восстановление (pg_restore):**
```bash
pg_restore -U username -d dbname backup.dump
```

**Резервирование одной таблицы:**
```bash
pg_dump -U username -d dbname -t tablename -F c -f table_backup.dump
```

**Восстановление в новую БД:**
```bash
pg_restore -U username -d newdbname backup.dump
```

**Резервирование всех БД кластера:**
```bash
pg_dumpall -U username -f full_backup.sql
```

### Задание 3. MySQL

3.1. С помощью официальной документации приведите пример команды инкрементного резервного копирования базы данных MySQL. 

*Приведите ответ в свободной форме.*

### 3.1. Инкрементное резервное копирование MySQL

**Требования:**
- Должна быть включена binary logging
- Необходим полный бэкап для основы

**1. Создание полного бэкапа:**
```bash
mysqldump --single-transaction --flush-logs --master-data=2 --all-databases > full_backup.sql
```
**2. Создание инкрементного бэкапа:**
```bash
mysqladmin flush-logs
cp $(ls -t /var/lib/mysql/mysql-bin.0* | head -n 1) /backups/incremental_backup_$(date +%Y%m%d_%H%M%S).bin
```

**3. Восстановление:**
```bash
# Восстановление полного бэкапа
mysql < full_backup.sql

# Применение инкрементных изменений
mysqlbinlog /backups/incremental_backup_*.bin | mysql
```

**Автоматизация через cron (ежечасно):**

```bash
0 * * * * /usr/bin/mysqladmin flush-logs && cp $(ls -t /var/lib/mysql/mysql-bin.0* | head -n 1) /backups/incremental_backup_$(date +\%Y\%m\%d_\%H\%M\%S).bin
```
